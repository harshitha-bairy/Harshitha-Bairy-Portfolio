## Uploading to GitHub
Upload every file in this folder directly into the repository root:
- index.html
- style.css
- script.js
- me.jpeg
- career.jpeg
- dance.jpeg
- hobbies.jpeg

No image folder is required. Do not upload the ZIP itself.
